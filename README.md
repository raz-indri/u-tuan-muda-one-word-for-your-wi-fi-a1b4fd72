# One Word for Your Wi-Fi

One word for home Wi-Fi, as it is actually lived with: **ghosting**.

It vanishes mid-call, mid-game, mid-sentence — no warning, no goodbye — then drifts back later as if nothing happened. Like being ghosted, except by your router.
